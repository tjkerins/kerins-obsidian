A read-only view of the Kerins software factory's jobs, written by `factory/bin/vault-export` into `Notes/Factory/`. GitHub and the factory's `factory/jobs/` folder are the record: make decisions on the pull request, not here. Notes you edit stop updating. Cost is an API-equivalent estimate, not a bill. Generated notes are gitignored and stay on the device or cloud session that ran the export; they don't sync through Git and disappear with a cloud session. For day-to-day status use the GitHub labels `factory:ready` and `factory:needs-human`.
